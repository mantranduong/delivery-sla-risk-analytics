# Publication checklist

- Original ZIP is unchanged.
- CSVs, model binary, original report and unfinished src scripts are intentionally excluded. Keep them in your private archive.
- Review notebook saved outputs for personal or restricted data before publishing.
- Verify dataset source/license and Tableau sharing permissions.
- Export actual SLA dashboard screenshots into assets and link them in README.
- Run notebooks locally and validate dependencies before claiming reproducibility.
- Upload the contents of this folder, not the ZIP itself, to GitHub.
